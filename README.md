# Portfolio - Esa Sanjaya

Website portofolio pribadi bertema cyber/hacker.

## Struktur File
```
index.html   -> struktur halaman (HTML)
style.css    -> seluruh styling (CSS)
script.js    -> seluruh interaktivitas (JavaScript)
images/      -> foto profil, hobi, dan tim favorit
```

## Cara Hosting ke GitHub Pages
1. Buat repository baru di GitHub, misalnya bernama `portfolio`.
2. Upload semua file & folder di atas ke repository tersebut (pertahankan strukturnya).
3. Masuk ke **Settings > Pages** pada repository.
4. Pada bagian **Source**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu beberapa menit, lalu situs akan aktif di:
   `https://<username-github>.github.io/<nama-repo>/`

## Menjalankan Secara Lokal
Cukup buka `index.html` langsung di browser, atau jalankan local server:
```
python3 -m http.server
```
